# 홈페이지 VM 비용 예측 개선

## 바꾼 내용

- 성능 비교를 처리량, 메모리, 예상 비용의 세 탭으로 구성했다. 처리량과 메모리는 기존 내부 랩 실측값을 사용한다.
- 메모리 절감 비율에 큰 VM 가격을 곱하던 문구를 제거했다. 예상 비용 탭에는 프레임워크별 VM 구성, 연간 선결제 금액, 월 환산 기본요금과 Spine 적용 시 예상 차액을 표시한다.
- 홈페이지와 벤치마크 보고서가 같은 데이터와 계산식을 사용한다. 한국어, 영어, 일본어, 중국어 간체와 번체에 반영했다.
- 탭의 좌우 방향키, Home, End 조작과 선택 상태를 지원한다. `?metric=cost`로 예상 비용 탭을 바로 열 수 있다.
- 계산 근거는 접어서 볼 수 있게 하고, 공개 상품 링크와 다운로드 가능한 JSON을 추가했다. 원본 계측 파일은 수정하지 않았다.

## 표시 금액

| 구성 | vpsGOD 상품 | 연간 표시 요금 | 월 환산 기본요금 |
|---|---|---:|---:|
| Spine | 2 vCPU / 256MB | $25 | 약 ₩2,782 |
| NestJS / Express | 3 vCPU / 6GB | $80 | 약 ₩8,902 |
| Spring MVC | 2 vCPU / 4GB | $60 | 약 ₩6,676 |
| FastAPI / Uvicorn | 4 vCPU / 8GB | $120 | 약 ₩13,353 |

비교군에도 확인한 공개 상품 중 저렴한 연간 할인 상품을 적용했다. 더 작은 일반 상품보다 큰 할인 상품이 저렴한 경우가 있다. 월 환산액은 연간 표시 요금을 12로 나눴으며, 환율은 2026-10-30 유럽중앙은행 기준값에서 구한 $1 = ₩1,335.27이다. 최초 청구서에만 적용되는 할인 코드는 사용하지 않았다.

## 예측 조건

초당 2만 요청에서 얻은 기존 CPU·메모리 기록을 사용한다. 클라우드 코어당 성능은 측정 환경의 50%, CPU 여유는 20%로 가정했다. RAM은 시작·예열을 포함한 관측 최대치의 1.25배에 경량 OS용 128MiB를 더하고, FastAPI 추가 워커 메모리를 선형 반영했다. 기존 연구 시나리오의 호스트 여유 256MiB를 모든 프레임워크에서 동일하게 128MiB로 낮춘 조건이다.

이 금액은 실제 최소 VM이나 p99 목표를 검증한 결과가 아니다. 할인 상품은 CPU를 공정 공유 방식으로 배분하며 지속 할당률 수치는 공개되지 않았다. 할인 상품의 지역, 최종 재고와 갱신 가격은 확인하지 않았다. 추가 트래픽과 세금은 제외한다. Spine 상품의 포함 전송량은 100GB이며, 표시 금액으로 초당 2만 요청을 한 달 내내 처리할 수 있다는 의미는 아니다.

CPU 여유 30% 시나리오도 공개 JSON에 보존했다. 이때 Spring MVC는 3코어, FastAPI는 5코어가 필요하다는 추정이 나온다. 확인한 공개 VPS 목록에서 5코어 이상 단일 상품을 찾지 못했으므로 그 조건의 FastAPI 가격은 제공하지 않는다.

## 화면 확인

기존 디자인을 유지하는 성능 비교 영역의 변경이다. 새 디자인 방향을 추첨하지 않고 기존 색상과 서체를 사용했다. 실제 데이터를 비교하는 탭이 상호작용 요소이며, 사진이나 장식 요소를 추가하지 않았다.

전체 페이지의 테이스트 검사에는 변경 전후 동일한 기존 지적 4개가 남는다. 보라색 브랜드, 사진 개수, 측정 보고서 링크를 통계 숫자의 보조 제목으로 인식하는 항목, 닫힌 언어 메뉴의 숨김 상태다. 이번 비용 UI의 새 정적 검사 지적은 없었다. 전역 검사를 통과했다고 보고하지 않는다.

## 검증

- `npm run docs:build` 성공. 기존 번들 크기 경고는 남는다.
- Chromium 48개, WebKit 16개 브라우저 검사 통과. 5개 언어, 320~1440px 화면, 밝은/어두운 테마, 보고서, 바로가기와 공개 JSON을 확인했다.
- 기존 처리량·메모리 수치, 예상 요금·차액, 방향키·Home·End 탭 조작, 계산 근거 펼치기, 가로 넘침 여부를 확인했다. 검사 중 브라우저 예외는 없었다.
- 1440px, 768px, 390px 최종 화면을 직접 확인했다. 데스크톱은 설명을 왼쪽에 배치해 빈 공간을 줄였고, 모바일은 한 열로 표시한다.
- 원본 실측 자료와 클라우드 운영 기록은 변경하지 않았다. 브라우저 산출물은 Git에서 제외한다.
