# Installation

Install Spine CLI and start development in a project generated by the CLI. This guide targets Spine CLI **0.1.4** and the generated Spine dependency **v0.5.1**.

## Requirements

- Go **1.25.5 or later**. The CLI's recommended and verified version is **1.27.3**.
- Add Go's executable installation directory to `PATH`. If `GOBIN` is unset, the default is `$(go env GOPATH)/bin`.

```bash
go version
```

## Install the CLI

This site uses the `spine` executable.

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@v0.1.4
spine version
```

If `spine` is not found after installation and `GOBIN` is unset, add the default binary directory to the current Bash or Zsh session. Save the same setting in your shell startup file for future sessions. If you set `GOBIN`, add that directory instead.

```bash
export PATH="$(go env GOPATH)/bin:$PATH"
spine version
```

The version output is `spine-cli 0.1.4`.

## Generate a project

Run this from the parent directory where you want to create the project.

```bash
spine new my-app --module example.com/my-app
cd my-app
go mod tidy
```

The CLI pins Spine `v0.5.1` in `go.mod`. Prepare dependencies with `go mod tidy`.

The generated `spine.toml` contains:

```toml
module = "example.com/my-app"
entrypoint = "."
composition = "./internal/application"
port = 8080
```

`BuildApplication()` in `internal/application/application.go` registers components and `GET /health`. The generated `main.go` calls it, validates the app with `app.Validate(options)`, then calls `app.Run(options)`.

## Verify and run

```bash
spine doctor
spine inspect
spine contract check
spine verify
```

`doctor` diagnoses tools and project configuration; `inspect` shows the registered execution contract. `contract check` validates the static contract, and `verify` runs contract, gofmt, vet, and test checks. The generated `application_test.go` also checks `BuildApplication()` and `app.Validate(options)` without starting a server.

After the checks pass, run `spine dev` and check the actual HTTP response from another terminal.

```bash
spine dev
```

```bash
curl http://localhost:8080/health
```

The response is `{"status":"ok"}`. Stop the development server with `Ctrl+C`. Local verification and external database, broker, or deployment E2E checks are separate.
