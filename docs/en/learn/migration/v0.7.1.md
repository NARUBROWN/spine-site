# Spine v0.7.1

Spine v0.7.1 is the release baseline for updated HTTP inputs and routing, OpenAPI, and runtime options. Existing v0.6.5 applications can migrate incrementally.

## Key changes

- Register HTTP routes in a controller’s `RegisterRoutes` and register constructors with `constructor.Controller`. Existing `app.Route` remains available during migration and is deprecated.
- Use `input.Path`, `input.Query`, and `input.Body` to declare input sources. Path inputs support structs and scalars. Check the restrictions on mixing old and new inputs.
- Generate OpenAPI from registered routes and serve the bundled Swagger UI and ReDoc.
- HTTP v3 supports shared body processing and TLS with a choice of Echo or net/http.
- The CLI supports dependency channels, event and WebSocket platforms, validators, and frontend configuration.


## Create a stable project

After installing the CLI, select stable dependencies with `--channel main`. In interactive creation, select Main explicitly. `spine update` retains the channel recorded in the project.

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@latest
spine new my-app --module example.com/my-app --channel main --no-interactive
cd my-app
spine verify
spine dev
```

If the installed CLI is older than `v0.4.3-rc.1` or compatible stable platform tags are unavailable, use the following alternative. The RC channel may select a newer core, so pin the core after generation and check `go.mod`.

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@v0.4.3-rc.1
spine new my-app --module example.com/my-app --channel rc --no-interactive
cd my-app
go get github.com/NARUBROWN/spine@v0.7.1
go mod tidy
spine verify
spine dev
```
