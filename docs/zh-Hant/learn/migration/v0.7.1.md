# Spine v0.7.1

Spine v0.7.1 是更新 HTTP 輸入與路由、OpenAPI 及執行選項的發布基準。現有 v0.6.5 應用程式可以逐步遷移。

## 主要變更

- 在控制器的 `RegisterRoutes` 註冊 HTTP 路由，並使用 `constructor.Controller` 註冊建構函式。現有 `app.Route` 在遷移期間仍可使用，但已棄用。
- 使用 `input.Path`、`input.Query`、`input.Body` 宣告輸入來源。路徑輸入支援結構體和純量。請確認新舊輸入的混用限制。
- 根據已註冊路由產生 OpenAPI，並提供內建的 Swagger UI 和 ReDoc。
- HTTP v3 支援共用請求本文處理和 TLS，可選擇 Echo 或 net/http。
- CLI 支援選擇依賴頻道、事件和 WebSocket 平台、驗證器及前端設定。


## 建立正式版專案

安裝 CLI 後，使用 `--channel main` 選擇正式版相依套件。互動式建立時請明確選擇 Main。`spine update` 會保留專案中記錄的通道。

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@latest
spine new my-app --module example.com/my-app --channel main --no-interactive
cd my-app
spine verify
spine dev
```

如果已安裝的 CLI 低於 `v0.4.3-rc.1`，或者相容的正式平台標籤尚未提供，可用以下命令取代上述命令。RC 通道可能選擇更新的核心，因此產生後請固定核心並檢查 `go.mod`。

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@v0.4.3-rc.1
spine new my-app --module example.com/my-app --channel rc --no-interactive
cd my-app
go get github.com/NARUBROWN/spine@v0.7.1
go mod tidy
spine verify
spine dev
```
