# 迁移到 0.7.5 API

升级到 Spine `v0.7.5` 时，请查看 HTTP 输入、上下文和应用组装方式的变化。

## 升级到正式版 {#stable-upgrade}

以下命令用于更新现有的 Echo 应用。如果使用其他 HTTP 实现，请在[平台指南](/zh-Hans/learn/getting-started/platforms)中确认兼容版本。使用 HTTP v2 的应用还需升级到对应的 HTTP v3 平台。

```sh
go install github.com/NARUBROWN/spine-cli/cmd/spine@v0.4.4
spine version
go get github.com/NARUBROWN/spine@v0.7.5 github.com/NARUBROWN/spine-echo-platform@v0.2.1
```

- [HTTP v3 迁移详情](https://github.com/NARUBROWN/spine/blob/v0.7.5/docs/migration/http-v3.md)
- [运行时 OpenAPI 配置](/zh-Hans/reference/api/openapi)

## 控制器与 DTO

```go
type UserPath struct {
	ID int64 `path:"id"`
}
type UserQuery struct {
	Name string `query:"name"`
}
type UserHeaders struct {
	RequestID string `header:"X-Request-ID"`
}
type CreateUser struct {
	Name string `json:"name" validate:"required"`
}

func (*UserController) RegisterRoutes(r *api.Registry) {
	users := r.Group("/users", api.Interceptors((*Auth)(nil)))
	users.GET("/:id", func(path input.Path[UserPath]) httpx.Response[map[string]int64] {
		return httpx.Response[map[string]int64]{Body: map[string]int64{"id": path.ID}}
	})
	users.POST("/", func(body input.Body[CreateUser]) httpx.Response[CreateUser] {
		return httpx.Response[CreateUser]{Body: *body, Options: httpx.ResponseOptions{Status: 201}}
	})
}
```

统一使用 input.Path[UserPath]、input.Query[UserQuery]、input.Header[UserHeaders]。HTTP 普通 *DTO 会被拒绝。Path/Query/Header 默认 lowerCamel，可用标签覆盖。Body 遵循 json/xml/form 解码规则。仅允许一个成功响应，多响应以及无效或冲突 XML 标签在准备阶段被拒绝。

## 组装与自动验证

```go
engine, err := playground.New()
if err != nil {
	return nil, boot.Options{}, err
}
app := spine.New(echoplatform.Option(), spine.WithValidator(engine))
app.Constructor(
	constructor.Repository(&UserRepository{}),
	constructor.Service(&UserService{}),
	constructor.Controller(&UserController{}),
	constructor.Interceptor(&Auth{}),
)
```

将此片段放入具有所需类型与导入的 BuildApplication。engine 是 playground.New 实例。自动标签验证不需要 DTO Validate 方法。额外方法须自行实现并在需要时调用 (*body).Validate()，OpenAPI 不推断其方法体。app.Validate 检查应用配置。构造函数仅支持单返回值，拒绝可变参数。

## 上下文与拦截器

HTTP 处理器需要请求上下文时可以声明 pkg/spine.Ctx。所有拦截器钩子都接收 pkg/spine.Ctx。仍兼容直接注入标准 context.Context。数据库和事件使用 ExecutionContext().Context()，执行值使用 Set/Get，HTTP/WS 使用公开视图。全局和路由 PreHandle 均在绑定前执行。BeforeResponse 错误优先决定响应，HTTPError 只允许 400–599。AfterCompletion 在写入尝试后执行，不是提交点。

[公开上下文](/zh-Hans/reference/api/execution-context) / [作用范围](/zh-Hans/learn/tutorial/4-interceptor) / [事务](/zh-Hans/learn/tutorial/6-transaction)

## CLI 与兼容代码

CLI `v0.4.4` 生成 `RegisterRoutes`、角色构造器和 HTTP 输入包装类型。迁移后运行 `go mod tidy`、`spine contract check` 和 `spine verify`，再验证实际的 HTTP 请求。 app.Route、route.WithInterceptors、query.Values、header.Values、path、multipart.UploadedFiles 均为已弃用兼容 API，不用于新示例或生成代码。旧迁移文档描述历史行为，当前 API 以本页为准。

## 从 0.7.1 迁移 {#from-v071}

如果应用使用已撤回的 Go 模块版本 `v0.7.1`，请升级到 `v0.7.5`。为现有 HTTP 处理器中的 DTO 指针加上与输入来源对应的包装类型，并将 HTTP 平台更新到兼容版本。
