# Spine v0.7.1

Spine v0.7.1 是更新 HTTP 输入和路由、OpenAPI 及运行选项的发布基准。现有 v0.6.5 应用可以逐步迁移。

## 主要变更

- 在控制器的 `RegisterRoutes` 中注册 HTTP 路由，并使用 `constructor.Controller` 注册构造函数。现有 `app.Route` 在迁移期间仍可使用，但已弃用。
- 使用 `input.Path`、`input.Query`、`input.Body` 声明输入来源。路径输入支持结构体和标量。请检查新旧输入的混用限制。
- 根据已注册路由生成 OpenAPI，并提供内置的 Swagger UI 和 ReDoc。
- HTTP v3 支持共享请求体处理和 TLS，可选择 Echo 或 net/http。
- CLI 支持选择依赖渠道、事件和 WebSocket 平台、验证器和前端配置。


## 创建正式版项目

安装 CLI 后，使用 `--channel main` 选择正式版依赖。交互式创建时请明确选择 Main。`spine update` 会保留项目中记录的渠道。

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@latest
spine new my-app --module example.com/my-app --channel main --no-interactive
cd my-app
spine verify
spine dev
```

如果已安装的 CLI 低于 `v0.4.3-rc.1`，或者兼容的正式平台标签尚不可用，可用以下命令替代上述命令。RC 渠道可能选择更新的核心，因此生成后请固定核心并检查 `go.mod`。

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@v0.4.3-rc.1
spine new my-app --module example.com/my-app --channel rc --no-interactive
cd my-app
go get github.com/NARUBROWN/spine@v0.7.1
go mod tidy
spine verify
spine dev
```
