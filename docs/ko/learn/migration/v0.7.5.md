## 컨트롤러와 DTO

```go
type UserPath struct {
	ID int64 `path:"id"`
}
type UserQuery struct {
	Name string `query:"name"`
}
type UserHeaders struct {
	RequestID string `header:"X-Request-ID"`
}
type CreateUser struct {
	Name string `json:"name" validate:"required"`
}

func (c *UserController) RegisterRoutes(r *api.Registry) {
	users := r.Group("/users", api.Interceptors((*Auth)(nil)))
	users.GET("/:id", c.Get)
	users.POST("/", c.Create)
}
func (c *UserController) Create(ctx spinectx.Ctx, body input.Body[CreateUser]) httpx.Response[CreateUser] {
	return httpx.Response[CreateUser]{Body: *body, Options: httpx.ResponseOptions{Status: 201}}
}
```

같은 방식으로 input.Path[UserPath], input.Query[UserQuery], input.Header[UserHeaders]를 받습니다. 일반 *DTO는 HTTP 입력으로 거부합니다. Path/Query/Header는 태그 없이 lowerCamel 이름을 쓰고 필요할 때 외부 이름을 지정합니다. Body는 json/xml/form 디코더 규칙입니다. 성공 응답은 하나이며 다중 응답은 준비 단계에서 거부합니다. XML의 잘못된 태그 조합이나 충돌도 준비 단계에서 거부합니다.

## 앱 조립과 자동 검증

```go
engine, err := playground.New()
if err != nil {
	return nil, boot.Options{}, err
}
app := spine.New(echoplatform.Option(), spine.WithValidator(engine))
app.Constructor(
	constructor.Repository(&UserRepository{}),
	constructor.Service(&UserService{}),
	constructor.Controller(&UserController{}),
	constructor.Interceptor(&Auth{}),
)
```

위 조각은 필요한 타입과 import를 갖춘 BuildApplication에 둡니다. engine은 playground.New의 인스턴스입니다. 자동 태그 검증에 DTO Validate 메서드는 필요하지 않습니다. 추가 메서드는 직접 구현하고 필요한 곳에서 (*body).Validate()로 호출하며 OpenAPI는 본문 규칙을 추론하지 않습니다. app.Validate는 앱 구성 검사입니다. 생성자는 단일 반환값만 지원하고 가변 인자는 거부합니다.

## 컨텍스트와 인터셉터

핸들러와 모든 훅은 pkg/spine.Ctx를 사용합니다. 표준 context.Context 직접 주입도 호환 지원합니다. DB와 이벤트에는 ExecutionContext().Context(), 실행별 값에는 Set/Get, HTTP와 WebSocket에는 전송별 공개 뷰를 사용합니다. 전역과 라우트 PreHandle은 모두 바인딩 전입니다. BeforeResponse 오류가 응답에 우선하며 HTTPError는 400~599만 허용합니다. AfterCompletion은 응답 시도 뒤여서 커밋 장소가 아닙니다.

[공개 컨텍스트](/ko/reference/api/execution-context) / [적용 범위](/ko/learn/tutorial/4-interceptor) / [트랜잭션](/ko/learn/tutorial/6-transaction)

## CLI와 호환 코드

현재 생성기는 RegisterRoutes, 역할 생성자와 입력 래퍼를 생성해야 합니다. 생성 후 contract check와 verify, 실제 HTTP 요청을 확인합니다. 기존 app.Route, route.WithInterceptors, query.Values, header.Values, path와 multipart.UploadedFiles는 호환용 Deprecated API입니다. 새 예제나 생성 코드에 사용하지 않습니다. 과거 버전 이전 문서는 당시 동작을 설명하므로 이 페이지를 현재 기준으로 사용합니다.
