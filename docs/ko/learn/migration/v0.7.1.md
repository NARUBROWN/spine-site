# Spine v0.7.1

Spine v0.7.1는 HTTP 입력과 라우팅, OpenAPI, 실행 환경을 갱신한 정식 기준입니다. 기존 v0.6.5 앱은 아래 전환 안내를 따라 단계적으로 옮길 수 있습니다.

## 주요 변경

- 컨트롤러의 `RegisterRoutes`에 HTTP 경로를 등록하고 `constructor.Controller`로 생성자를 구성합니다. 기존 `app.Route`는 전환 기간에 유지되며 Deprecated입니다.
- `input.Path`, `input.Query`, `input.Body`로 입력 출처를 명시합니다. 경로 입력은 구조체와 스칼라를 지원합니다. 기존 입력과 새 입력의 혼용 제한을 확인하세요.
- 실제 라우트에서 OpenAPI 문서를 생성하고 내장 Swagger UI와 ReDoc을 제공할 수 있습니다.
- HTTP v3는 공통 본문 처리와 TLS를 지원하며 Echo와 net/http 플랫폼을 선택할 수 있습니다.
- CLI는 의존성 채널, 이벤트와 WebSocket 플랫폼, 검증기, 프론트엔드 구성을 선택할 수 있습니다.


## 정식 프로젝트 생성

CLI `v0.4.3`부터 새 프로젝트는 기본적으로 `main` 채널의 정식 의존성을 사용합니다. `--channel main`으로 명시할 수도 있습니다. `spine update`는 프로젝트에 기록된 채널을 유지합니다.

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@latest
spine new my-app --module example.com/my-app --channel main --no-interactive
cd my-app
spine verify
spine dev
```
