# 문서 안내

처음 앱을 만들거나 필요한 API를 찾을 때 아래 문서 지도를 이용하세요. 시작하기부터 운영까지의 문서는 정식 `v0.6.5`를 기준으로 하며, 미리보기 기능과 전환 안내는 별도 경로로 구분합니다.

처음이라면 [설치](/ko/learn/getting-started/installation) 후 [첫 번째 앱](/ko/learn/getting-started/first-app)을 따라가세요. 최신 실험 기능은 [미리보기 안내](/ko/learn/migration/preview-features)에서 확인할 수 있습니다.
