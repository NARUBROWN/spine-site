# 커뮤니티

Spine 사용 중 생긴 질문을 나누거나 버그와 개선 사항을 제안하려면 아래 채널을 이용하세요.

## 질문과 사용 경험 공유

Discord에서 Spine 사용 방법을 질문하고 다른 개발자와 사용 경험을 공유할 수 있습니다.

- [Spine Discord 초대 링크](https://discord.gg/8C7tAVzRKe)

## 버그 제보와 개선 제안

버그를 발견했거나 기능을 제안하려면 GitHub Issue를 작성하세요. 버그 제보에는 재현 방법, 예상 동작과 실제 동작, Go 버전과 운영체제 정보를 함께 적어 주세요.

- [Spine GitHub Issues](https://github.com/NARUBROWN/spine/issues/)

## 코드와 문서 기여

기능 추가, 버그 수정과 문서 개선에 참여할 수 있습니다. 구현 전에 Issue를 작성하고 유지관리자와 범위를 논의하는 절차는 기여 안내를 참고하세요.

- [기여 안내](/ko/community/contributing)
- [Spine GitHub 저장소](https://github.com/NARUBROWN/spine)

## 릴리스 채널과 설치

Preview, RC, 정식 채널의 선택과 발행 절차는 [릴리스 채널과 설치](/ko/community/release-channels)에서 확인하세요.
