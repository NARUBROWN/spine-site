# 버전 현황

Spine 생태계 저장소의 발행 태그, 다음 목표 버전과 변경사항을 확인하세요. 각 저장소는 자체 버전으로 발행합니다.

<ReleaseCatalog />

## 목록 읽는 방법 {#reading}

- **정식, Preview, RC**를 선택하면 해당 채널의 최신 태그와 발행 이력을 확인할 수 있습니다. 태그가 없는 채널은 발행 태그 없음으로 표시합니다.
- **다음 목표**는 Preview 브랜치의 발행 정책에 기록한 기본 버전입니다. 목표 버전이 적혀 있어도 태그가 발행됐다는 뜻은 아닙니다.
- **GitHub Release 게시됨**은 릴리스 페이지가 있다는 뜻입니다. **태그 생성됨**만 표시된 후보는 발행 실행과 검증 manifest를 함께 확인하세요. 코어 태그 생성과 전체 플랫폼 조합 검증 완료는 별도 단계입니다.
- 날짜는 GitHub Release 게시일입니다. 태그만 있는 후보에는 게시일을 표시하지 않습니다.

목록은 매일 GitHub의 공개 태그와 정책을 수집한 결과이며, 위 확인 시각을 기준으로 합니다. 수집 후의 변경은 각 저장소 링크에서 확인하세요. 채널 선택과 설치 방법은 [릴리스 채널과 설치](/ko/community/release-channels)를 참고하세요.

## 버전 기록을 남기는 위치 {#records}

| 기록 | 관리 위치 |
| --- | --- |
| 다음 기본 버전과 채널별 의존성 조합 | 각 저장소의 `.github/release-policy.json` |
| 해당 버전에 넣을 기능과 수정 | GitHub 마일스톤에 이슈와 PR 연결 |
| 변경사항과 호환성, 이전 방법 | [릴리스 노트](/ko/community/changelog)와 버전별 이전 안내 |
| 발행된 소스와 검증 결과 | 태그, 발행 실행과 release manifest |

Preview와 RC의 검증 기록은 Actions artifact로 남기며 보관 기간이 있습니다. 정식은 GitHub Release에 첨부한 manifest를 확인하세요. 이 페이지는 버전 목록을 제공하며, 태그만으로 전체 조합의 검증 완료를 판정하지 않습니다.
