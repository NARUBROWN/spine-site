# Spine v0.7.1

Spine v0.7.1 は HTTP 入力とルーティング、OpenAPI、実行オプションを更新したリリース基準です。v0.6.5 のアプリは段階的に移行できます。

## 主な変更

- コントローラーの `RegisterRoutes` に HTTP ルートを登録し、`constructor.Controller` でコンストラクターを登録します。既存の `app.Route` は移行期間中も利用できますが非推奨です。
- `input.Path`、`input.Query`、`input.Body` で入力元を指定します。パス入力は構造体とスカラーに対応します。新旧入力の混在制限を確認してください。
- 登録ルートから OpenAPI を生成し、同梱の Swagger UI と ReDoc を提供できます。
- HTTP v3 は共通のボディ処理と TLS に対応し、Echo または net/http を選択できます。
- CLI で依存関係のチャネル、イベントと WebSocket のプラットフォーム、バリデーター、フロントエンドを選択できます。


## 正式版プロジェクトの作成

CLI のインストール後、`--channel main` で正式版の依存関係を選びます。対話形式では Main を明示的に選択してください。`spine update` はプロジェクトに記録されたチャンネルを維持します。

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@latest
spine new my-app --module example.com/my-app --channel main --no-interactive
cd my-app
spine verify
spine dev
```

インストール済みの CLI が `v0.4.3-rc.1` より古い場合や、互換性のある正式プラットフォームタグが利用できない場合は、上記の代わりに以下を使えます。RC チャンネルはより新しいコアを選ぶ場合があるため、生成後にコアを固定し `go.mod` を確認します。

```bash
go install github.com/NARUBROWN/spine-cli/cmd/spine@v0.4.3-rc.1
spine new my-app --module example.com/my-app --channel rc --no-interactive
cd my-app
go get github.com/NARUBROWN/spine@v0.7.1
go mod tidy
spine verify
spine dev
```
