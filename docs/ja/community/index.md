# コミュニティ

Spine の使用中に生じた疑問を共有したり、バグや改善案を報告したりするには、以下のチャンネルをご利用ください。

## 質問と使用経験の共有

Discord で Spine の使い方を質問し、他の開発者と使用経験を共有できます。

- [Spine Discord 招待リンク](https://discord.gg/8C7tAVzRKe)

## バグ報告と改善提案

バグを見つけた場合や機能を提案する場合は、GitHub Issue を作成してください。バグ報告には、再現手順、期待する動作と実際の動作、Go のバージョンと OS の情報を記載してください。

- [Spine GitHub Issues](https://github.com/NARUBROWN/spine/issues/)

## コードとドキュメントへの貢献

機能の追加、バグの修正、ドキュメントの改善に参加できます。実装前に Issue を作成し、メンテナーと変更範囲を相談する手順は、貢献ガイドを参照してください。

- [貢献ガイド](/ja/community/contributing)
- [Spine GitHub リポジトリ](https://github.com/NARUBROWN/spine)

## リリースチャンネルとインストール

Preview、RC、安定版の選択と公開手順は[リリースチャンネルとインストール](/ja/community/release-channels)を参照してください。
