# バージョン一覧

Spine エコシステムのリポジトリについて、公開タグ、次の目標バージョン、変更内容を確認できます。各リポジトリは独自のバージョンで公開します。

<ReleaseCatalog />

## 一覧の読み方 {#reading}

- **正式、Preview、RC**を選ぶと、チャンネルの最新タグと公開履歴を確認できます。タグがない場合は公開タグなしと表示します。
- **次の目標**は Preview ブランチの公開ポリシーに記録した基本バージョンです。目標の記載はタグの公開を意味しません。
- **GitHub Release 公開済み**はリリースページがあることを示します。**タグ作成済み**のみの候補は、公開ワークフローと検証 manifest をあわせて確認してください。コアのタグ作成とプラットフォーム全体の組み合わせ検証完了は別の段階です。
- 日付は GitHub Release の公開日です。タグのみの候補には公開日を表示しません。

一覧は GitHub の公開タグとポリシーを毎日収集し、上記の確認日時を基準に表示します。その後の変更は各リポジトリのリンクで確認してください。チャンネルの選択とインストール方法は[リリースチャンネルとインストール](/ja/community/release-channels)を参照してください。

## バージョンの記録先 {#records}

| 記録 | 管理先 |
| --- | --- |
| 次の基本バージョンとチャンネル別の依存関係 | 各リポジトリの `.github/release-policy.json` |
| バージョンに含める機能と修正 | GitHub マイルストーンに関連付ける issue と PR |
| 変更、互換性、移行方法 | [リリースノート](/ja/community/changelog)とバージョン別の移行ガイド |
| 公開ソースと検証結果 | タグ、公開ワークフロー、release manifest |

Preview と RC の検証記録は保存期間のある Actions artifact です。正式版は GitHub Release に添付した manifest を確認してください。このページはバージョンの一覧であり、タグだけで組み合わせ全体の検証完了を判定しません。
